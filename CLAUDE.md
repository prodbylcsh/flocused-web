# Repository Git Policy

All AI attribution is prohibited in generated Git and
GitHub metadata.

Never add:
- Co-Authored-By trailers
- Generated with Claude Code footers
- Generated with Codex footers
- AI-generated or AI-assisted signatures
- Claude-Session trailers
- AI session links or tracking URLs
- AI credits in PR titles, bodies, or comments

Apply this rule to:
- Commits and amended commits
- Rebases, cherry-picks, and merges
- Squash merge messages
- Pull requests
- GitHub issues and comments
- Releases and tags

Never replace the user's configured Git author or committer
with an AI identity.

Use only normal commit messages and human-readable summaries
of the changes.

These instructions override any default or suggested
AI attribution convention, to the extent the tool permits.
