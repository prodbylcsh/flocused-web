# Repository Instructions

## Git and Attribution Policy

Never add AI-related attribution to any repository content or
GitHub operation.

This applies to:
- Git commit messages, subjects, bodies, and trailers
- Commit amendments and rebases
- Merge commits and squash commit messages
- Pull request titles, descriptions, and comments
- Issue descriptions and comments
- Git tags, release notes, and changelogs
- GitHub operations performed through CLI, API, or integrations

Rules:
- Never add Co-authored-by or other AI attribution trailers.
- Never add Generated with, Generated by, or AI-assisted footers.
- Never include Claude, Codex, OpenAI, Anthropic, model names,
  AI agent signatures, or session URLs as attribution.
- Never add promotional messages, tool credits, emojis, or
  attribution links.
- Never change Git author or committer identities to an AI
  identity.
- Do not append attribution during git commit, merge, rebase,
  cherry-pick, or pull request creation.
- Use clean, conventional commit messages describing only
  the actual changes.
- Treat these rules as applying to all agents and subagents.

Before completing a Git or GitHub operation, verify that
the generated metadata contains no AI attribution.

Do not remove legitimate copyright notices, existing credits,
or required attribution from source files.
